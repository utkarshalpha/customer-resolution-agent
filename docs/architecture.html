Voice — a real two-way conversation

  • Mic → MediaRecorder + RMS silence detector (0.9 s ends your sentence)
  • /api/stt → Groq Whisper large-v3-turbo transcribes
  • Transcript → same policy-checked agent → reply
  • /api/tts → Groq Orpheus natural voice; subtitles synced to audio time; browser speech as fallback
  • Self-healing: per-reply time budget + 2 s watchdog re-arms the mic — a lost audio callback can never freeze the loop; closing voice releases the mic hardware

Service rules enforced (§3)

  • Cancelled by airline → free rebooking ≤ 24 h OR full refund — customer's choice
  • Delay: < 3 h → ₹500 meal voucher · > 3 h → + lounge · > 5 h → + hotel for the delayed hours only (never a full night)
  • Refunds: 7 business days, original payment method ONLY
  • Fare difference: customer pays; waiver > ₹1,500 needs a supervisor
  • Gold/Platinum: priority rebooking, NO extra compensation

Three scenarios (§6 outcomes)

  • Priya · Gold · SK-204 cancelled → rebook free or refund; free upgrade "for the trouble" → escalated, never approved
  • Arvind · Silver · SK-118 +4 h → voucher + lounge; hotel declined (needs > 5 h); "make an exception" → ticket
  • Meher · Platinum · SK-305 +6 h → voucher + lounge + delayed-hours hotel (14:00–20:00); ₹2,000 higher-fare move → pay, supervisor waiver, or wait

Why it can't go rogue

  • LLM talks, code decides — actions exist only as tools; the policy layer re-derives every entitlement from the data pack
  • Only fare figure it can quote = what quote_fare_difference returns
  • Off-topic questions politely refused (KB-grounded); greetings/small talk allowed
  • Other passengers' data never enters the model's context — privacy by construction
  • Anger changes tone, never entitlements; escalation outcomes never promised

Record & delivery (non-negotiable)

  • Persistent audit log: every message, action, ticket, decision appended live; survives restarts; Download record (JSON) per case
  • Agent console (opt-in drawer): live rule trace — Allowed / Blocked / Escalated per turn
  • Deploy: Render free web service via one-click render.yaml blueprint (prompts for the Groq key); GitHub Pages static preview as fallback
  • Files: server.js · policy.js · agent-openai.js · engine.js (data pack + rules) · kb.js · app.js · admin.js
One sentence:  A free LLM holds a natural conversation (text or voice), but every action must pass a deterministic policy engine built from the data pack — anything beyond policy becomes a ticket a human approves, and the decision flows back into the chat, with the whole exchange preserved in a permanent case record.
