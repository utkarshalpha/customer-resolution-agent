Design principle03 / 10
The LLM never decides who gets compensation
💬

LLM

Conversation and reasoning: understands intent, empathises, plans which tool to call — Claude or free providers, same contract.

🔧

Tools

The only way facts are fetched and actions happen. Nine tools with strict schemas — no action exists outside them.

§

Policy engine

Business rules as deterministic code. Every tool call is checked; disallowed calls return the rule, never execute.

🧑‍⚖️

Human

The safety boundary. Beyond-policy asks, waivers over ₹1,500, and legal threats become tickets for a supervisor.

✕  An LLM wrapperUser → LLM → “Sure, here’s ₹2,000”
✓  This platformUser → LLM → tool call → policy check → authorized action → audit

Knowledge base, not vibes

§3 · Delay Compensation Rule
“Delay more than 5 hours: meal voucher + hotel accommodation, covering only the delayed hours (not a full night’s stay).”

The agent cites rules it retrieved, exactly as written. A disallowed tool call returns the rule that blocked it — the model must relay it and escalate, because paraphrasing policy into existence isn’t possible.

Why Render, not Pages/Vercel
